# RAW Alphonso Mango — Premium Interactive Website

Experience the rich, raw taste of 100% pure Alphonso mangoes, cold-pressed to perfection. This landing page features a fully automated, cinematic interactive animation sequence that loads and plays seamlessly in the browser.

🔗 **Live Demo Link**: [https://aldojason.github.io/animated/](https://aldojason.github.io/animated/)

*(Note: To activate this live link, please enable GitHub Pages in your repository settings on GitHub. See the instructions below).*

---

## ✨ Features

- 🎬 **Autoplay Cinematic Intro**: A smooth 200-frame image sequence that plays automatically on page load via GSAP, showing a mango splash rising and forming the juice bottle.
- 📱 **Retina / High-DPI Support**: Canvas draws are dynamically scaled to the device pixel ratio for crystal-clear graphics on Retina displays.
- 🌊 **Fluid Scroll Inertia**: Integrated with Lenis smooth scroll for a cushioned and premium scrolling experience across all page sections.
- 🎯 **Interactive Hotspots**: Once the bottle is formed, pulsing markers appear, allowing users to hover and inspect product components (Cap, Ingredients Label, and HPP Bottle base).
- 🏷️ **Dynamic Flavor Themes**: Users can switch between flavors (Alphonso Original, Spicy Mango Chili, Mango Coconut Cream). Clicking cards shifts the entire body's radial background gradient to match the flavor profile.
- 🧮 **Pack Price Calculator**: A functional order widget to calculate quantities, apply bulk discounts (10% off for 12-packs, 20% off for 24-packs), and trigger a Canvas Confetti blast upon pre-order.
- 💬 **Sleek FAQ Accordions**: Clean collapsable panels built with CSS transitions.
- 🖱️ **Magnetic Custom Cursor**: A custom dot and follower cursor that reacts to interactive elements.

## 🛠️ Local Development

To run the project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/Aldojason/animated.git
   cd animated
   ```
2. Start a local server:
   - If you have Python: `python -m http.server 8000`
   - If you have Node: `npx serve`
3. Open your browser and go to: `http://localhost:8000`
